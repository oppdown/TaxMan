Changelog

Small, practical improvements focused on entering records quickly and preparing a clean handoff.

September 9, 2026

0.2.1 · Faster entry and safer file handling

  • Added File → Save and Save As.
  • Added File, Edit, View, and Help menus with keyboard shortcuts.
  • Added first-letter category selection, including U for Utilities.
  • Home-office entries default to 33% business use.
  • Separated PDF/CSV notices from backup notices.
  • Added guarded double-confirmation company-data cleanup.
  • New transactions start with a blank date and Enter saves to the ledger list.

September 8, 2026

0.2.0 · Multi-year local ledger

  • Added multi-year transaction entry and year-based reports.
  • Added compact date entry such as 090826.
  • Added Companies & Sources, backups, CSV export, and tax-preparer PDF reports.
