Changelog

Small, practical improvements that make a tax-preparer handoff easier.

September 11, 2026

0.2.4 · Welcome to TaxMan

  • Renamed the desktop application from Tax Ledger to TaxMan across the app, reports, exports, and Windows packages.
  • Updated the in-app brand mark and all site/favicon locations with the TAXMAN icon.
September 9, 2026

0.2.3 · Restore you can trust

  • Restored JSON data now appears in the ledger immediately.
  • Backups with entries from another year now open on the year containing those entries.
  • Moved the app’s File / Edit / View / Help actions into one native Windows menu.
September 9, 2026

0.2.2 · A cleaner handoff

  • Restored backup data now immediately repopulates the open app.
  • Empty ledgers no longer show an unnecessary back-up-first warning.
  • Moved confirmations and status notices to the lower-right corner.
  • Kept one File / Edit / View / Help menu bar.
  • Refreshed the public site with dedicated download and changelog pages.
September 9, 2026

0.2.1 · Faster entry and safer file handling

  • Added File → Save and Save As.
  • Added first-letter category selection, including U for Utilities.
  • Home-office entries default to 33% business use.
  • Added guarded company-data cleanup.
  • New transactions start with a blank date and Enter saves to the ledger.
September 8, 2026

0.2.0 · Multi-year local ledger

  • Added multi-year transaction entry and year-based reports.
  • Added compact date entry such as 090826.
  • Added Companies & Sources, backups, CSV export, and PDF reports.
